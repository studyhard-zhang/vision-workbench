# 视训工作台桌面版 0.36.2

本项目仅用于学习和二次开发，基于 Ultralytics YOLO26 模型进行训练。

运行 VisionWorkbench-Setup-0.36.2-x64.exe，按中文向导安装。无需另装 Python、Git 或 Node.js。

首次使用选择“创建新工作区”，默认存放于 %LOCALAPPDATA%\VisionWorkbenchData\var，可选择其他空目录。新工作区不含项目、图片、权重或连接。

已有数据选择“使用已有工作区”，指向包含 platform.db 的目录。程序与工作区必须分开，升级和卸载保留数据。旧服务需正常退出后再打开新版。

安装器检查 WebView2，缺少时从微软服务器安装运行时，需要联网。离线电脑可提前安装微软 WebView2 Evergreen x64。当前应用安装包未数字签名。

安装后从桌面或开始菜单打开“视训工作台”，创建项目、导入图片、定义缺陷类别、标注、检查划分并生成数据版本。训练及 GPU 推理需连接用户自行准备的本机 WSL2 或 Linux SSH 计算环境；工作台校验并报告缺失项，不自动安装环境。

产线漏检图片补标后，生成新数据版本，在已有模型点击“基于此模型训练下一版”。TensorRT 部署包需在产线目标 GPU 上构建引擎并验收效果。

请使用存储与备份功能备份项目。整目录搬迁前退出所有使用该工作区的服务，再复制完整目录，不要仅复制运行中的数据库。SSH 密码由当前 Windows 用户加密，换电脑需重新配置。

日志及工作区配置存放于 %LOCALAPPDATA%\VisionWorkbench。桌面版优先使用 8765，被其他工作区或程序占用时自动选择空闲端口，日志记录实际端口。所选工作区保持不变；同一工作区已被旧版本服务打开时，请先正常退出该旧服务，再启动新版。关闭客户端不会中止远端 GPU 任务，需要中止时使用工作台并等待资源释放确认。
