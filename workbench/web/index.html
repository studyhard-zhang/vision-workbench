          使用前需要准备什么
          软件负责保存连接、核对设备身份、校验依赖、传输训练数据并管理任务。
          用户需自行准备 NVIDIA 驱动、Linux x86_64（Windows 使用 WSL2）、Python 3.10–3.12、CUDA 版 PyTorch/Torchvision、Ultralytics 8.4.203、模型权重和可写训练目录。SSH 方式还需 root 登录账号、SSH/SFTP 服务、地址端口及网络连通。
          本机方式复用已登记的 WSL 训练连接。首次使用请自行准备 WSL 内的训练环境和本机 SSH/SFTP 服务，再选择“首次登记本机 WSL”，填写已有本机SSH端口和登录信息完成登记。
