# v0.36.2

- 修复桌面版因首选端口被其他工作区占用而无法启动的问题。
- 首选端口不可用时自动使用空闲端口，保持安装时选定的工作区。
- 同一工作区的同版本服务继续复用；工作区锁及版本检查保留。
- 日志记录实际使用的端口，退出仅关闭当前客户端创建的服务。

# v0.36.1

本项目仅用于学习和二次开发，基于 Ultralytics YOLO26 模型进行训练。

- 项目首页、用户说明和训练环境说明增加统一声明。
- 源码与 Windows 安装包包含项目声明，安装目录可查看“项目声明.txt”。
- 训练逻辑及数据库格式保持一致。

# v0.36.0

- 提供 Windows x64 桌面安装包，内置控制端 Python。
- 安装向导支持首次创建空工作区及选择已有工作区，拒绝覆盖非空目录。
- 升级及卸载保留外部工作区，程序默认按当前用户安装。
- 工程目录统一为 workbench，公开文档面向安装、使用和构建。
- 默认计算目标为未连接，用户连接并校验自己的训练环境。
- 支持检测与分割标注、类别分层划分、模型持续迭代及 TensorRT 产线交付。

安装包不含业务数据、预训练权重、GPU 驱动和训练环境。WebView2 缺失时安装需要联网。安装包当前未数字签名。

详见项目根 README.md 及 docs/安装与使用.md。
