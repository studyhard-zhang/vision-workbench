# 安装与使用

> 本项目仅用于学习和二次开发，基于 Ultralytics YOLO26 模型进行训练。

## 下载与安装

适用 Windows 10 2004 及以上、Windows 11，x64 系统。

1. 进入 [最新版本](https://github.com/studyhard-zhang/vision-workbench/releases/latest)，在 Assets 下载名称含 `Setup` 和 `x64.exe` 的文件。GitHub 自动生成的 Source code ZIP 是开发源码。
2. 双击安装器，选择程序安装位置。无需安装 Python、Git、Node.js。
3. 首次使用选择“创建新工作区”。默认 `%LOCALAPPDATA%\VisionWorkbenchData\var`，也可选其他空目录。已有业务数据选择“使用已有工作区”，指定包含 `platform.db` 的目录。
4. 完成安装，打开桌面或开始菜单的“视训工作台”。首次新建工作区为空，点击“创建项目”开始。

安装器在缺少 WebView2 时运行微软官方引导程序，需要联网；离线电脑可先手动安装 [WebView2 Evergreen Standalone x64](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。当前应用安装包未数字签名，下载来源及 SHA-256 可在发布页核对。

可在 PowerShell 校验安装包，结果应与同版本 `SHA256SUMS.txt` 一致：

```powershell
Get-FileHash .\VisionWorkbench-Setup-0.36.2-x64.exe -Algorithm SHA256
```

## 第一次使用

1. 创建项目和图片数据集，导入图片。
2. 创建目标检测或实例分割任务，定义缺陷类别并完成标注。可使用统一 ROI 与高倍缩放。
3. 检查与划分中选择类别分层，检查训练/验证分布。图片不可拆分；类别只有一个独立样本或分组冲突时，需补充数据或调整分组。
4. 生成冻结数据版本，连接并校验训练环境，启用训练设备。
5. 选择数据版本创建训练，点击开始训练，查看日志与结果。创建训练本身不会自动开始计算。
6. 查看模型，进行图片推理或导出产线部署包。

训练环境由用户或管理员准备，见 [训练环境准备](训练环境准备.md)。只管理数据与标注时无需先连接 GPU。

## 模型迭代与产线部署

产线漏检图片补标后生成新数据版本，进入已完成模型，点击“基于此模型训练下一版”，使用其 best.pt 继续训练。保留旧模型及其冻结数据。

TensorRT 部署包包含 ONNX、类别和目标端构建/推理脚本。在产线设备上构建匹配的引擎；不同 GPU、系统和 TensorRT 版本不能直接共用开发机引擎。连续拍照时复用包内 Detector 实例，实际速度和 FP16 检测效果需用产线图片验收。

## 升级、备份与迁移

升级前在“存储与备份”保存项目备份，保存标注并退出旧服务，再运行新版安装器。选择“使用已有工作区”，核对目录。安装、升级和卸载只管理程序，外部业务数据与客户端配置保留。

整目录搬迁前正常退出所有使用该工作区的服务，再复制整个工作区，包含数据库及其配套文件、原图、版本、训练、模型和结果。不要在服务运行时只复制 platform.db。另一种方式是在软件中生成项目备份，并恢复到独立目录。

SSH 密码由 Windows 当前用户 DPAPI 加密，换电脑需要重新配置连接，不能继承其他设备的 GPU 校验证据。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 新建工作区提示目录非空 | 选空目录；已有数据改选“使用已有工作区”，不会自动清理目录 |
| 8765 已被其他工作区或程序占用 | v0.36.2 起桌面版自动使用空闲端口，继续打开安装时选中的工作区 |
| 提示所选工作区已由旧版服务打开 | 正常退出使用该工作区的旧客户端或源码服务，再启动新版；同一工作区不能同时运行两个写入服务 |
| 安装后看不到原项目 | 新建工作区为空；通过安装向导选择“使用已有工作区”，指向原 platform.db 所在目录 |
| 训练环境未通过 | 在连接报告中查看缺失依赖、权重、驱动、权限等项，由管理员按指引处理后重新校验 |
| CUDA 显存不足 | 手动降低批大小或输入尺寸，核对精度影响后创建新训练；任务不会自动降低参数重跑 |
| 启动失败 | 日志位于 `%LOCALAPPDATA%\VisionWorkbench` 中 desktop.log、console.log |

关闭客户端不会中止已启动的远端 GPU 任务。需要中止时使用工作台操作并等待进程与资源释放确认。
