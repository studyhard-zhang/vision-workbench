# 构建与发布

普通用户使用 Releases 中的 Setup.exe。以下面向维护者，在 Windows x64 上构建。

```powershell
cd workbench
py -3.13 -m venv .build-env
.\.build-env\Scripts\python.exe -m pip install -r desktop/requirements-build.lock.txt
```

安装 [Inno Setup 6](https://jrsoftware.org/isdl.php)，将微软官方 [WebView2 引导程序](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) 保存为 `.runtime/build-tools/MicrosoftEdgeWebview2Setup.exe`。核对其 Microsoft 签名。

```powershell
.\.build-env\Scripts\python.exe tools/build_desktop.py --iscc 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

输出在 `deliverables`，包含安装包及构建清单；文件校验和用于检查完整性。仓库不提交安装包，通过 GitHub Release 附件分发。发布前运行回归测试，并在独立目录验证首次创建、已有工作区、升级、卸载保留与桌面加载。测试不能使用业务工作区。

源码精简包可用 `python tools/build_release.py --output deliverables/VisionWorkbench-Source.zip` 生成。不要上传 `.runtime`、业务工作区、连接配置、权重、私有证据或构建环境。

客户端通过程序版本、schema 和规范化工作区路径校验正在运行的服务，只复用一致服务，不结束未知进程。安装器只在用户明确选择创建新工作区时初始化空库，已有工作区保持原文件。
